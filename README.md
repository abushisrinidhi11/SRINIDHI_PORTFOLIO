# Srinidhi Portfolio

Personal portfolio of Abushi Srinidhi, a full-stack developer based in Hyderabad.

A single static page (`index.html`): plain HTML, CSS and a little JavaScript.
No build step, no backend and no environment variables are needed.

## Run locally
Open `index.html` in a browser, or run `npx serve .` in this folder.

## Deploy
Vercel: import this repo, choose the "Other" preset, leave build command and output directory empty, then deploy.
Render: create a Static Site, leave the build command empty and set the publish directory to `.`.

## Edit
All content lives in `index.html`. Change the text, commit, and push; the host redeploys automatically.
